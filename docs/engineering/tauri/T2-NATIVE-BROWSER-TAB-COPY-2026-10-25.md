## Important user-facing distinction

Using the existing copy tab button in a Tauri native child WebView copies the genuine current page URL, **not an Electron browser control link**. A URL can be pasted into chat or opened by the Agent's separate controlled browser, but browser cookies/session/access cannot be inherited across that boundary. This branch chooses truthful partial functionality instead of forging a dangerously misleading Agent tab mention.
